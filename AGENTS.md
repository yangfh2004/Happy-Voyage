# Repository instructions

- The [Chinese gameplay rules (GAMEPLAY.md)](GAMEPLAY.md) are the single source of truth for gameplay. Any PR that changes player-facing rules, values, or behavior must update the corresponding Chinese documentation in the same PR. Whenever `GAMEPLAY.md` changes, update the [English translation (GAMEPLAY.en.md)](GAMEPLAY.en.md) in the same PR. Link to these documents rather than duplicating rules in other documentation, and keep in-game help consistent with the canonical rules.
